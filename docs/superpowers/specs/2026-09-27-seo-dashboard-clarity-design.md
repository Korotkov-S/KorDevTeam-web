# Понятная SEO-панель — спецификация

Дата: 27 сентября 2026 года.

## Цель

Заменить неоднозначные графики SEO-кабинета на управленческий экран, который прямо отвечает на вопросы: какие ключевые запросы отслеживаются, где находится сайт в Яндексе по России и городам, какие запросы растут или падают и где ещё нет данных.

## Контроль семантического ядра

- Главная сводка строится по последнему контрольному снимку Яндекса для среза «Россия, компьютеры» и явно называет этот срез.
- Карточки показывают количество активных запросов, запросов в топ-3, топ-10, топ-30, вне топ-100 и без свежего снимка.
- Отдельно показывается количество выросших и упавших запросов относительно снимка ровно за предыдущий день и ровно за семь дней. Если сопоставимого снимка нет, изменение не выдумывается.
- Переход из `not_found` в найденную позицию считается ростом, обратный переход — падением. `not_found` никогда не становится позицией 0.

## Матрица запросов и регионов

- Одна строка соответствует одному активному запросу семантического ядра, даже если контрольных снимков ещё нет.
- Базовые столбцы: ключевой запрос, Wordstat в месяц, ВЧ/СЧ/НЧ, целевая страница.
- Для России и каждого настроенного города отображаются две строки: компьютер и смартфон; для каждой — текущая позиция, изменение за день и семь дней либо явное «нет данных» / «вне топ-100».
- Дата последнего снимка отображается в формате `дд.мм.гггг`.

## Официальные метрики показов

- Показатели Вебмастера и Search Console остаются отдельными от контрольных позиций.
- Разрезы по устройствам, регионам и частотности показываются таблицами с явными столбцами «Показы» и «Клики», а не одинаковыми безымянными столбцами.
- Если у Яндекса есть только агрегат по России, кабинет прямо сообщает, что городских данных по фактическим показам пока нет.
- Если все фактические запросы не классифицированы, вместо бессмысленного графика показывается предупреждение.

## Редактирование семантического ядра

- Таблица редактирования получает отдельные заголовки: «Ключевой запрос», «Целевая страница», «Wordstat/месяц», «ВЧ/СЧ/НЧ», «Тип запроса», «Приоритет», «Статус», «Действие».
- Неочевидные заголовки имеют доступные подсказки с расшифровкой.
- Дублированное read-only представление целевой страницы и приоритета удаляется.

## Ограничения

- Средняя позиция по реальным показам не смешивается с контрольной позицией Search API.
- UI не создаёт позиции и динамику при отсутствии снимков.
- Google остаётся только в Search Console; городская матрица контрольных позиций относится к Яндексу.
- Таблицы должны сохранять читаемость через горизонтальную прокрутку на узких экранах.
