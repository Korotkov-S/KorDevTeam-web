## Full compatible snapshots

One eligible snapshot is one distinct successful run whose actual stored observations match its exact planned prompt IDs, with repetitions1/2/3 per question, completed=stored=planned=3×questions, and a completion timestamp. All rows must share platform, surface, mode, language, region and the same actual observation sessionPersonalized boolean; a known run personalization must agree. A run with mixed personalization, missing/duplicate rows, a partial status or false counters is not eligible. Filtering a topic or prompt subset must not hide a missing row elsewhere in the planned run: fetch and validate the full run before projecting the requested subset. Raw evidence stays readable even if excluded from aggregate analytics.

Compatibility additionally requires the same prompt IDs/fingerprint and stable current prompt definitions. Reject historical runs whose current prompt updatedAt is later than run.startedAt: the old definition is not provable. This conservative guard may reject an unchanged-text priority edit, but never invents an old definition. Current prompt category labels describe the current catalogue, not a reconstructed historic category. Snapshot keys retain all dimensions and exact IDs; duplicate run IDs cannot count as independent snapshots. Three distinct complete compatible snapshots are required for an observation-based recommendation/experiment. Three weeks are neither necessary nor sufficient. Comparing mixed conditions is explicitly incomparable; zero or fewer than three compatible snapshots is insufficient, not no visibility.

Keep existing mention/citation/share numerators and denominators. Share of Voice is relative only to the currently confirmed tracked entity set, not the whole market; candidate competitors never enter it. Descriptive category buckets are not instructions or evidence-backed recommendations. Overall descriptive totals may contain several cohorts and must be labelled as such; growth, decision readiness and experiment metrics are cohort-specific.
